This installs JDK 25 for Mavericks, based on the OpenJDK source code, built to run on Mac OS X 10.9 (Mavericks) and later on Intel Macs, into /usr/local/mavergreen/jdk25/, and registers it with Mac OS X as /Library/Java/JavaVirtualMachines/mavergreen-jdk25.jdk.

Open a new Terminal window: java-25 and javac-25 are on your PATH, and /usr/libexec/java_home -v 25 finds this JDK.

The installer finishes by generating the JDK's class data sharing archive, which makes the JDK start faster. If that step fails, the JDK still works, and the reason is in /var/log/install.log.

A background updater (Sparkle) checks daily for new releases. This is an unofficial community build, not affiliated with or endorsed by Oracle or the OpenJDK Community.
